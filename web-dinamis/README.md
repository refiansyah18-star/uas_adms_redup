# WatchVault - Web Dinamis PHP + MariaDB

Pengganti penuh folder `web-dinamis`.

## Stack

- PHP 8.2 Apache
- MariaDB 11.4
- Docker Compose
- GitHub Actions
- AWS EC2

## Fitur

- Landing page dark streaming style
- Dashboard statistik dengan Chart.js
- Watchlist film/anime dengan gambar
- Search dan filter
- Tambah tontonan
- Edit tontonan
- Detail tontonan
- Hapus tontonan

## Deploy

Web dinamis berjalan di:

```txt
http://54.255.162.1:3000/
```

## Catatan

Folder ini menggantikan FinChat. Hapus folder `web-dinamis` lama, lalu extract ZIP ini ke root repo.
